# Complex 复数练习项目

> 说明：本 README 已按“新人入门讲解”组织内容，可直接作为 onboarding 讲解提纲使用。

这是一个面向 C++ 初学者的**复数类练习工程**，重点是通过一个小型代码库学习：
- 类的封装（头文件声明 + 源文件定义）
- 运算符重载
- 工程组织（Visual Studio 解决方案 / 项目结构）

## 目录结构

- `Complex/Complex.sln`：Visual Studio 解决方案文件。
- `Complex/Complex/Complex.vcxproj`：C++ 项目文件。
- `Complex/Complex/Complex.h`：`Complex` 类声明。
- `Complex/Complex/Complex.cpp`：`Complex` 类实现。
- `Complex/Complex/main.cpp`：程序入口，演示基础调用。
- `Complex.mdj`、`复数.xmind`：设计/学习过程材料。

## 新人上手重点

1. 先从 `main.cpp` 看程序如何创建复数对象与读取属性。
2. 阅读 `Complex.h`，理解对外接口（构造函数、运算符、共轭、模长、getter）。
3. 再看 `Complex.cpp`，把每个函数与数学公式对应起来。
4. 在本地新增样例，验证 `+ * /`、共轭、模长是否符合预期。

## 当前代码里值得注意的问题（可作为练习任务）

- 运算符参数与成员函数缺少 `const`，会限制可用场景。
- 赋值运算符建议返回 `Complex&`，并接受 `const Complex&`。
- 乘法虚部公式目前写法与标准公式不一致，可用单元测试验证并修正。
- 除法未处理分母为 0 的情况。
- 目前缺少 `operator<<` 等输出支持，调试体验一般。

## 后续学习建议

- **第一阶段（1~2 天）**：
  - 补充一组手算可验证的测试用例（如 `(1+2i)*(3+4i)`）。
  - 修复乘法虚部公式。
- **第二阶段（2~3 天）**：
  - 全面引入 `const` 正确性。
  - 调整 `operator=` 签名为规范写法。
- **第三阶段（3~5 天）**：
  - 增加输入输出重载（`operator<<`、可选 `operator>>`）。
  - 为除法增加异常/错误处理策略。
- **第四阶段（进阶）**：
  - 学习并应用规则三/五（拷贝构造、移动语义）。
  - 迁移到 CMake 或引入跨平台构建流程。
